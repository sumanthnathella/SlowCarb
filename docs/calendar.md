## Make this week yours

- **To edit meals:** click the pencil icon on this page. It opens the starter plan's source on GitHub. Change a row under **Seven-day menu**, keeping the four columns and Day 1–7 order.
- **To edit breakfast:** change **Fixed breakfast, every day** in that same source file. Both this calendar and the starter plan update on the next build.
- **Keep shopping in sync:** update the shopping quantities and any affected recipes when changing a meal. The shopping list is written guidance, not an automatic calculator.
- **Sunday is flexible, not a binge:** gluten and dairy considerations still apply. You can repeat an ordinary day instead.

This is a reusable reference, not a dated tracker or a personalized calorie/protein prescription. Meal portions and tolerance still matter. See the [framework](principles.md) for context.
